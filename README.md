# Interactive Personal & Business Engineering Portfolio

Modern, interactive full-stack engineer and AI/ML portfolio featuring an interactive orbit ring navigation hub, architectural case studies, project fee estimator, instant discovery booking scheduler, and live customization system.

## Features
- **Interactive Orbit Hub**: Dynamic rotating ring portal linking 7 core portfolio milestones.
- **Deep-Dive Case Studies**: Production system architectures, metric breakdowns, and interactive walkthroughs.
- **Service & Scope Estimator**: Interactive dynamic project calculator with realistic budget estimations.
- **Discovery Scheduler**: Direct discovery session booking with live `.ics` calendar invitation generator.
- **Live Theme & Preset Switcher**: Dynamic styling presets with instant responsive theme switching.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation & Local Run
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
