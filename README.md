## 💻 Local Setup & Development

Follow these instructions to run the portfolio locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/Aditya1791/FullStack-Portfolio.git

# 2. Navigate to the project root
cd FullStack-Portfolio

# 3. Install required dependencies
npm install

# 4. Start local Vite development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the interactive interface.

### Production Build
```bash
# Compile and validate TypeScript & build production bundle
npm run build

# Preview production bundle locally
npm run preview
```

## 🌐 Deploying to GitHub Pages

This repository is pre-configured with automated GitHub Actions deployment.

1. Push your changes to the `main` branch:
   ```bash
   git push origin main
   ```
2. In GitHub, go to **Settings** $\rightarrow$ **Pages** $\rightarrow$ **Source** and select **`GitHub Actions`**.
3. GitHub will build and publish the site to:
   $$\text{\url{https://aditya1791.github.io/FullStack-Portfolio/}}$$
